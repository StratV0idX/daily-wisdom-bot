# DailyWisdomBot

A simple and interactive Telegram bot that provides motivational quotes on demand.

---

## Features

* 📩 `/start` – Welcome message
* 💡 `/quote` – Get a random inspirational quote
* 📖 `/help` – View available commands
* 💾 Saves quotes locally in a JSON file

---

## Tech Stack

* Python
* Telegram Bot API
* Requests (API calls)

---

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/yourusername/DailyWisdomBot.git
cd DailyWisdomBot
```

---

### 2. Install dependencies

```
pip install -r requirements.txt
```

---

### 3. Set environment variables

Create a `.env` file in the project root:

```
BOT_TOKEN=your_telegram_bot_token
API_KEY=your_api_key
```

---

### 4. Run the bot

```
python main.py
```

---

## Bot Usage

Open your bot in Telegram:

👉 https://t.me/dailywisdoms_bot

Use:

```
/start
/quote
/help
```
